# Proyecto Mi Pueblo

## Introducción

El proyecto es una pequeña web promocional de mi pueblo Pradolamata (provincia de Burgos).

La web consta de página principal con la historia del pueblo, una pequeña galería de imágenes y una página con un formulario de contacto.

## Instalación

Descargar desde el Github en instalar en servidor o lanzar Live Server desde el Visual Code Studio.
